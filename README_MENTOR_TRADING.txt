MENTOR TRADING - ARCHIVO INICIAL

Este paquete contiene el diario web inicial. Todavía NO está conectado a Supabase ni tiene IA.

Para publicarlo con GitHub Pages:
1. Extrae este ZIP en tu computadora.
2. En tu repositorio GitHub, pulsa Add file > Upload files.
3. Sube index.html y pulsa Commit changes.
4. En Settings > Pages, en Build and deployment elige Deploy from a branch; Branch: main y folder: /(root); Save.

IMPORTANTE:
- Este primer archivo guarda los datos localmente en el navegador.
- No pegues aquí contraseñas, claves secretas ni service_role.
- Antes de migrar tu operación ya registrada, abre el diario anterior y usa Historial > Exportar respaldo JSON. Conserva ese JSON para importarlo en la nueva página.
- La conexión segura a Supabase y el análisis con IA se añaden en el siguiente paso; no introduzcas credenciales en este archivo todavía.
